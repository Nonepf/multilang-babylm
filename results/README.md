# Reported result snapshot

`paper_blimp_scores.csv` is a transcription of Appendix Table 8 in the
camera-ready manuscript. It contains all 35 conditions/seeds and all three
BLiMP columns. It is provided so that the paper's TI and TB arithmetic can be
audited without downloading checkpoints.

This CSV is **not raw lm-eval output** and must not be treated as independent
evidence that the runs were reproduced. Raw logs, checkpoint metadata, exact
dataset revisions, and the pinned evaluation-harness revision are not present
in this repository.
